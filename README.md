ПР1. Ответы на контрольные вопросы
1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки зрения того, когда обнаруживаются ошибки? 
 В C# специальный компилятор проверяет весь код на ошибки ЗАРАНЕЕ, еще до запуска. Если есть хоть одна опечатка, программа просто не соберется. В Python код читается и выполняется строчка за строчкой прямо во время запуска, поэтому ошибка выскочит только тогда, когда система дойдет до "сломанной" строки.
 2. Что делает команда `dotnet run` на самом деле — из каких двух шагов она состоит?
 Сначала она запускает сборку (dotnet build), которая переводит наш код в понятный для компа файл, а вторым шагом сразу этот получившийся файл запускает.
 3. Зачем нужны папки `bin/` и `obj/` и почему их не нужно хранить в Git? 
 Там хранятся временные файлы, которые пк создает сам при каждом запуске программы (всякий кэш и готовый .exe файл). В Git их кидать не надо, потому что они весят много, постоянно меняются и их можно в любой момент сгенерировать заново через dotnet run. Они скрыты в .gitignore.
 4. В чём разница между `git commit` и `git push?  
   Commit — это сохранение изменений у себя на пк (как точка сохранения в игре). А push — это отправка этих сохранений в интернет на сайт GitHub.
5. Чем отличаются конкатенация строк через `+` и интерполяция через `$"..."`? Какой способ предпочтительнее и почему?
 Конкатенация — это когда мы склеиваем текст через плюсы, постоянно открывая и закрывая кавычки. Интерполяция — это когда мы пишем текст внутри `$"..."`, а переменные просто суем в фигурные скобки `{}`. Интерполяция намного лучше, потому что код получается короче, аккуратнее и в нем сложнее запутаться.
 6. Что произойдёт, если разделить `int` на `int`, если результат должен быть дробным? Как это исправить?  
 Будет целочисленное деление, то есть C# тупо выкинет всю дробную часть после запятой (например, 25 / 4 даст просто 6). Чтобы это исправить, надо перед одной из переменных написать `(double)`, чтобы перевести ее в дробный тип.
 7. Чем `const` отличается от обычной переменной? Приведите свой пример, когда стоит использовать `const`.
 Обычную переменную можно менять в коде сколько угодно раз (например, баланс денег). А константа (`const`) задается один раз и навсегда, поменять ее нельзя. Пример: количество месяцев в семестре (`const int Months = 4;`), оно ведь фиксированное.
 8. Что такое top-level statements и чем они отличаются от классического класса `Program { static void Main() }`?
 Это когда можно писать код в файле `Program.cs` сразу с первой строчки, без лишней писанины. В старом классическом варианте приходилось обязательно создавать кучу оберток типа `class Program` и `static void Main()`, из-за чего три строчки кода превращались в десять.
